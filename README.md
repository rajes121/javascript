# JavaScript Assignments and Capstone Project

This repository contains my JavaScript practical assignments and a mini capstone project. I created these programs to practice the fundamentals of JavaScript, including variables, operators, conditional statements, loops, functions, arrays, and objects.

## Assignments

### Assignment 1: Variables and Data Types
- Declaring variables using `var`, `let`, and `const`
- Checking data types using `typeof`
- Displaying output using `console.log()`

### Assignment 2: Operators and Input Handling
- Taking user input with `prompt()`
- Converting input using `Number()`
- Calculating a bill, tip, and total amount

### Assignment 3: Conditional Statements
- Using `if...else` to calculate grades
- Using `switch` to evaluate the grade
- Checking pass or fail using a ternary operator

### Assignment 4: Loops
- Printing a multiplication table
- Using `while` loops and `break`
- Practicing `do...while` and `continue`

### Assignment 5: Functions and Scope
- Creating regular and arrow functions
- Using parameters and default values
- Understanding block scope and `ReferenceError`

### Assignment 6: Arrays and Objects
- Creating an array of product objects
- Using `forEach()`, `filter()`, and `map()`
- Generating formatted product information

## Capstone Project: Product Inventory and Analytics Dashboard

The capstone project combines the concepts from all six assignments in a single application.

### Features
- Add products through user input
- Validate product names and prices
- Prevent duplicate product names
- Categorize products as Budget, Standard, or Premium
- Calculate the total inventory value
- Filter affordable products
- Generate a formatted inventory report
- Demonstrate discount and tax calculations

### Technologies Used
- JavaScript
- HTML
- Browser Developer Tools

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser for the capstone project.
4. Enter the requested information in the prompts.
5. Open the browser console to view the output.

Individual assignments can be run separately in a JavaScript environment. Assignments that use `prompt()` should be run in a browser.

The purpose of this project is to strengthen my JavaScript fundamentals through practical coding exercises and apply those concepts to a small inventory management application.
